## 台账工作方式

1. 开始或恢复时先读状态页和相关日志的续接摘要。使用固定 ID `YYYY-MM-DD-简短主题`，同一目标续用 ID，独立目标另立关联工作。登记状态、执行者、占用及下一步。缺失的身份标识如实记录。
2. 写共享资源前重读索引，协调占用。同一资源串行修改。发现状态页有其他更新时，基于新版本只更新相关条目。登记是协作约定。
3. 使用 {{记录时区}}。讨论与只读检查可合并简记。变更与高风险操作记授权、实际参数、结果、验证及恢复方法；保留失败与中断。附件区分证据、回退副本与可重建产物，保存前脱敏。
4. 收尾更新实际验收、遗留或暂停条件与下一步，释放已结束的占用。只更新受影响的最新事实，区分配置、运行和功能验证。关闭任务保留短索引，旧记录留原日志。
